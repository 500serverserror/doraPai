# 麻将对局记分小程序

麻将等牌局的**分数记录**工具（仅记分，不涉及真实转账）：支持**创建多个对局**，每个对局通过**转发分享或二维码**邀请其他用户扫码进入，进入后在该对局内记分——**记入方加分、记出方（你自己）扣分**，对局内总分守恒，支持 1 / 2 / 8 / 16 快捷分数。数据保存在**微信云开发**云端，多人各自手机使用、分数互通。

## 功能

- **对局列表**（首页）：展示我参与的所有对局（名称、人数、我的分数、时间），可**新建对局**。
- **对局记录**：记录每次对局结束后的信息（对局名、结束时间、各成员最终分数），随对局结束自动生成。
- **对局详情**：对局内所有成员头像及实时分数，点击头像记分（预设 1/2/4/8/16/32 + 自定义）；顶部「邀请码」「二维码」用于分享邀请；「结束对局」可关闭对局并查看总分。

## 技术说明

- 登录：无需密码，微信静默登录，以 `openid` 作为唯一账号（无法冒充他人）。
- 数据模型（云数据库，首次调用自动创建集合）：
  - `users`：昵称、头像
  - `sessions`：对局（名称、6 位邀请码、创建者、时间）
  - `sessionMembers`：对局成员关系
  - `sessionScores`：成员在对局内的分数（每个对局独立账本）
  - `transfers`：记分流水（含 sessionId）
- 记分：单云函数 `api`，记分走 `runTransaction` 事务，加减同原子完成；对局外用户不能记分，不能记给自己。
- 二维码：云函数调用 `wxacode.getUnlimited` 生成小程序码（scene 携带邀请码）并存入云存储。

## 部署步骤

> 多人互通必须使用**自己的小程序 AppID**（当前已配置 `wxa331943c1022b913`），游客模式无法使用云开发。云环境 `cloud1-d5g8ig6zr9da1d1b4` 已写入 `app.js`。

1. **导入项目**：微信开发者工具 → 导入项目 → 选择本文件夹（`mahjong-book-v2`）。
2. **开通云开发**（若尚未开通）：工具栏「云开发」→ 开通并创建环境（环境 ID 为 `cloud1-d5g8ig6zr9da1d1b4`）。
3. **部署云函数**：右键 `cloudfunctions` 根目录 →「当前环境」→ 选择 `cloud1-d5g8ig6zr9da1d1b4`；再右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」。
4. **设置数据库权限（实时同步必需）**：云开发控制台 → 数据库 → 找到 `sessionScores` 和 `sessions` 两个集合 → 权限设置 → 都改为「**所有用户可读，仅创建者可写**」。不设置则"对局内实时同步刷新"与"结束对局同步"不会生效（记分/结束后其他成员需手动重进页面刷新）。
5. **编译运行**：点「编译」。首次打开提示设置昵称，设置后进入对局列表。
5. **多端联调**：
   - 转发分享：预览/真机后，对局页点「转发」发给另一台手机，对方点卡片即可进入对局。
   - 二维码：**小程序需先发布**（开发阶段小程序码生成接口不可用），发布后对局页「二维码」即可生成，扫码进入。

## 使用流程

1. 打开小程序 → 设置昵称/头像（即"登录"完成）。
2. 「对局」页 → 新建对局（可填名称）→ 进入对局详情。
3. 分享：点「转发」发给好友，或「二维码」生成小程序码（需发布后）。
4. 好友扫码/点卡片 → 自动加入对局 → 成员出现在列表。
5. 对局中点击对方头像 → 选 1 / 2 / 8 / 16 或自定义 → 确认记分：**记入方 +X，你的分数 -X**。

## 数据与安全说明

- 每个微信用户一个账号（openid），对局与分数存云端，换设备不丢失；分数可为负（记分特性），对局内总分守恒。
- 对局详情只返回成员昵称/头像/分数（成员 `_id` 用于记分），不暴露他人 openid。
- 记分限制：须为对局成员、不能记给自己、分数须为正整数、单笔上限 10 万分。
- 邀请码 6 位（去易混淆字符），凭码即可加入对局；对局无人数上限（建议麻将 4 人）。
